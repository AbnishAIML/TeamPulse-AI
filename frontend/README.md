# TeamPulse AI Frontend (TechTrix'26 BONUS 02)

A React + Vite dashboard prototype for the Intelligent Project Management and Team Contribution Analysis Platform.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally
1. Extract this ZIP.
2. Open the extracted `teampulse-ai-frontend` folder in VS Code.
3. Open a terminal in that folder.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL shown by Vite (usually http://localhost:5173).

## Included
- Responsive dark SaaS dashboard
- Sidebar navigation
- Project progress and workload charts
- Search and task filters
- Create-task modal
- Mark-task-done interaction
- Demo notifications and AI insight navigation

## Important
This is a frontend prototype with sample/demo data. It is not connected to a backend or database yet. Some navigation pages reuse the dashboard shell; API integration, real authentication, persistent data, task dependencies and actual AI calculations are next steps.
